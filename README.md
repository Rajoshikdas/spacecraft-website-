# 🚀 Aurelia Spacecraft Explorer

A stunning, immersive, and highly interactive space-themed web application showcasing the cutting-edge **Aurelia Spacecraft** and its missions. Experience high-tech interstellar visualization, mission statistics, and launch simulations in real-time.

🌌 **Live Demo:** [spacecraft1.netlify.app](https://spacecraft1.netlify.app)

---

## ✨ Features

- **🛸 Immersive Sci-Fi Hero Section:** Clean, high-tech dark mode aesthetic with vibrant cosmic gradients and smooth hover effects.
- **📊 Real-time Stats & Telemetry:** Dynamic statistics dashboard tracking core metrics like travel distance, cruise speed, and system status.
- **🚀 Interactive Launch Simulator:** Launch mission modal simulation powered by rich micro-animations.
- **🛡️ Partners & Aerospace Collaborations:** Integrated partners showcase representing elite interstellar networks.
- **✨ Fluid Animations:** Built with modern motion libraries for a premium, responsive feel.

---

## 🛠️ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** [Motion (Framer Motion)](https://motion.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## 🚀 Running Locally

Follow these simple steps to run the project on your machine.

### Prerequisites
Make sure you have **Node.js** (v18 or higher recommended) and **npm** installed.

### 1. Clone the Repository
```bash
git clone https://github.com/Rajoshikdas/spacecraft-website-.git
cd spacecraft-website-
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000` to view the application.

---

## 📦 Deployment & Build

To generate a highly optimized production bundle:
```bash
npm run build
```
This generates a static build in the `dist` directory, fully ready for static hosting services like Netlify, Vercel, or GitHub Pages.
